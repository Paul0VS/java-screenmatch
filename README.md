# Estudos e Práticas em Java

Repositório criado para armazenar exercícios e práticas desenvolvidos durante meus estudos de programação em Java.

## 📚 Conteúdos

- **Estudos:** exercícios e práticas de programação.
- **Perfil:** prática com apresentação de informações.
- **Soma:** operações de adição.
- **Subtração:** operações de subtração.

## 🛠️ Tecnologias

- Java
- IntelliJ IDEA
- Git e GitHub

## 🎯 Objetivo

Praticar lógica de programação, desenvolver habilidades na linguagem Java e acompanhar minha evolução durante os estudos.

Projeto educacional desenvolvido como parte da minha jornada de aprendizado em programação.
